# RU CUCCINA - Massas & Risotos

Cardápio digital moderno e responsivo para o restaurante **RU CUCCINA**, desenvolvido com HTML5, CSS3 puro e JavaScript.

## 🚀 Funcionalidades
- 📱 Interface 100% responsiva (Celular, Tablet e Computador)
- 🔍 Busca em tempo real por pratos e ingredientes
- ✨ Filtros por categorias (*Todos os Itens, Massas, Risotos, Combos*)
- 🛍️ Sacola de compras interativa com controle de quantidades e cálculo de subtotal
- 💬 Finalização de pedidos pronta para integração via WhatsApp

## 🛠️ Tecnologias
- HTML5 Semântico
- CSS3 Moderno (Vanilla CSS com Flexbox, Grid e Variáveis Customizadas)
- JavaScript Vanilla
- Google Fonts (Cormorant Garamond, Playfair Display, Plus Jakarta Sans)
